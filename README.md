# Student-Utility-System
Collaborative C project using Git


## About the Project
The **Student Utility System** is a collaborative C programming project developed to make common student-related calculations and tasks easier. It provides simple and efficient programs to help students perform useful academic operations.

## Objectives
- To simplify common student-related calculations.
- To develop programs using the C programming language.
- To understand Git and GitHub collaboration.
- To learn teamwork, version control, and repository management.

## Technologies Used
- C Programming Language
- Git
- GitHub
- Git Bash

## Collaboration
This project is developed by a team of students. Each team member contributes individual program files to the main repository using Git branches and collaborative development practices.

## Project Structure
The repository contains separate C source files for different student utilities.

## Conclusion
This project helps us improve our programming skills while gaining practical experience in collaborative software development using Git and GitHub.
